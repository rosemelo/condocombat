# Backend - CondoCombat

Este diretório contém a API do sistema CondoCombat.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Framework:** FastAPI / Alembic
- **Testes & Quality:** Pytest / Flake8
- **Containerização:** Docker

## 🚀 Como Executar Localmente
Consulte o arquivo `docker-compose.yml` na raiz do projeto para subir o ambiente completo.
